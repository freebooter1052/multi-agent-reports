## 🎯 Problem Statement
- Imagine trying to solve a puzzle where some pieces are missing; this paper tackles the core challenge of improving system reliability and performance in multi-agent environments.
- These results suggest that memory-aware link enforcement covers a gap left by prompt-level and topology-level defenses.

- Think of the system architecture like a blueprint for a high-tech factory. Data flows in, gets processed by specialized components, and produces a smart output.
- We introduce Memory-Aware Propagation and Link Enforcement Guard, MAPLE-Guard, a memory-link guard for memory-enabled MAS.

- Appendix A details the signal sources and distinguishes them from evaluator-only attack labels We evaluate MAPLE-Guard across reasoning, long-term memory, tool-use, and transfer benchmarks using benchmark-specific attacks and multiple MAS topologies.
